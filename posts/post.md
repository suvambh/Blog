# Building This Blog with FastHTML and MonsterUI

This blog using FastHTML and MonsterUI, and it was surprisingly simple. Here's how to do it.

## What I Used

- **FastHTML**: A Python library for building server-rendered web apps without JavaScript
- **MonsterUI**: Pre-styled components built on FrankenUI and Tailwind CSS
- **fh-posts**: A library that handles markdown blog posts automatically

## Conclusion

If you know Python and want to build a blog without dealing with complex frameworks, FastHTML + MonsterUI + fh-posts is a great stack. Simple, fast, and effective.
